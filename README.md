## Overview

Orange VPN provides high-speed, encrypted proxy and VPN connectivity designed to safeguard your online identity, bypass geo-restrictions, and provide unrestricted internet access with zero activity logging.

### Key Capabilities

- **Strict Zero-Logs Policy**: Your browsing activity, DNS queries, and destination IPs are never recorded or stored.
- **Dual-Protocol Local Core**: Supports both SOCKS5 and HTTP/HTTPS CONNECT tunnels for system-wide routing.
- **Global High-Speed Network**: Low-latency edge nodes situated in key international regions (Hong Kong, USA, Germany, Singapore, Japan, UK).
- **DNS Leak Protection**: Automatically shields against DNS leaks and blocks ISP-level inspection.
- **Cross-Platform Availability**: Dedicated client apps for Windows desktop, Android mobile, and Chromium extensions.
